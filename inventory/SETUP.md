# 함께 쓰는 재고장 — 처음 설정하기

팀원이 구글 계정으로 로그인해서 쓰는 재고 관리 앱입니다. 수량을 바꿀 때마다 **로그인한 구글 계정**으로 입출고 기록이 남습니다. 기록은 아무도 고치거나 지울 수 없습니다.

데이터는 본인 소유의 Firebase 프로젝트(무료 요금제)에 저장됩니다. 아래 설정은 처음에 한 번만 하면 됩니다.

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 관리자 구글 계정으로 접속합니다.
2. **프로젝트 추가**를 누르고 이름을 정합니다(예: `team-stock`). Google 애널리틱스는 꺼도 됩니다.

## 2. 구글 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 누릅니다.
2. **Sign-in method** 탭에서 **Google**을 고르고 **사용 설정**을 켭니다. 지원 이메일을 고른 뒤 **저장**합니다.

## 3. 데이터베이스 만들고 보안 규칙 넣기
1. **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
2. 위치는 `asia-northeast3 (서울)`을 고르고 **프로덕션 모드**로 시작합니다.
3. 만들어지면 **규칙** 탭을 엽니다. 이 폴더의 `firestore.rules` 내용 **전체**를 복사해서 붙여넣고 **게시**를 누릅니다.

> 이 규칙이 "등록된 팀원만 사용", "기록은 로그인 계정으로만 남김", "기록은 수정·삭제 불가"를 서버에서 강제합니다.

## 4. 앱 주소 허용하기
**Authentication → 설정 → 승인된 도메인 → 도메인 추가**에 아래 주소를 넣습니다.

```
jonghyun6364-afk.github.io
```

(`localhost`는 처음부터 들어 있어서 PC에서 테스트할 때도 로그인됩니다.)

## 5. 앱에 Firebase 연결하기
1. 왼쪽 위 톱니바퀴 → **프로젝트 설정 → 일반** 탭 → 아래쪽 **내 앱**에서 웹 아이콘 `</>`을 누릅니다.
2. 앱 닉네임(예: `재고장`)을 넣고 **앱 등록**을 누릅니다. Firebase Hosting은 체크하지 않습니다.
3. 화면에 나온 `firebaseConfig` 값(apiKey, authDomain, projectId …)을 `inventory/firebase-config.js`에 붙여넣습니다. Claude에게 붙여넣어 주면 대신 넣어 줍니다.

## 6. 배포
GitHub에 올리면 아래 주소에서 열립니다(가계부·냉장고 앱과 같은 GitHub Pages).

```
https://jonghyun6364-afk.github.io/household-ledger/inventory/
```

## 7. 팀원 추가
1. 관리자 계정(`firebase-config.js`의 `OWNER_EMAIL`)으로 로그인합니다.
2. **팀원** 탭에서 팀원의 구글 이메일을 추가합니다.
3. 팀원에게 위 주소를 보내면, 그 이메일로 로그인해서 바로 쓸 수 있습니다.

| 권한 | 할 수 있는 일 |
|---|---|
| 팀원 | 품목 등록·정보 수정, 입고·출고·실사 조정 |
| 관리자 | 팀원 권한 전부 + 품목 삭제, 팀원 추가·제거·권한 변경 |
| 소유자 (`OWNER_EMAIL`) | 항상 관리자. 목록에서 제거되지 않음 |

## 관리자(소유자) 이메일 바꾸기
두 곳을 똑같이 고친 뒤, `firestore.rules`를 3단계처럼 Firebase 콘솔에 다시 게시합니다.
- `inventory/firebase-config.js`의 `OWNER_EMAIL`
- `inventory/firestore.rules`의 `ownerEmail()`

## 무료 사용량
Firestore 무료 요금제는 하루에 읽기 50,000회, 쓰기 20,000회까지입니다. 입출고 한 번에 쓰기 2회(품목 + 기록)가 쓰이므로, 소규모 팀에서는 넘기 어렵습니다. 카드를 등록하지 않으면 요금이 나오지 않습니다.
